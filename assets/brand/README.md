# Brand masters

The source art for every PrintStream app icon (app-standards ASSET-2, ASSET-3):

- `icon.svg`: the mark on a square canvas with a 7% margin each side, the app-icon master.
- `icon-maskable.svg`: the mark on a full-bleed square in the background colour, for surfaces that crop their own shape.
- `icons.json`: devkit-icons' targets and background colour.

`npm run icons` regenerates every output and `npm run check:icons` (in validate) fails when one drifts. Change a master here, never an output.

| Output | Generated by |
| --- | --- |
| PWA icons in `apps/web/public`, and `assets/generated/icon-256.png` and `icon-512.png` for the README, website and promo catalog | devkit-icons (`icons.json`) |
| The tray icons, the standalone executables' icon and the desktop app's `apps/desktop/assets/app.ico` (all fifteen ASSET-5 frames) | `packages/sea-runtime/scripts/generate-tray-icons.mjs` |
| The Android launcher, monochrome and splash icons | `apps/mobile/scripts/android-branding.mjs`, at Android setup time |
| The Home Assistant integration's `brand/icon.png` and `icon@2x.png` (trimmed square, 256 and 512 px; the icon doubles as the logo) | `scripts/ha-brand/brand-images.mjs` (`npm run icons:ha`) |

## Exceptions to devkit-icons

- **Home Assistant**: devkit-icons has no Home Assistant target, and the brand rules want the mark trimmed of the master's margin. Moves to devkit if a second integration needs it.

- **Windows `.ico`**: one drawing serves the tray (self-hosted server and bridge), the standalone executables and the desktop app, so it is generated where the tray needs it, in sea-runtime, from the same master. devkit's Windows target would give the app icon a source the tray does not share.
- **Android**: the mark's two-colour gradient is kept in the adaptive icon through `aapt:attr`, which devkit-icons does not support for Android masters (it accepts flat `<path d fill>` art only). Android moves to devkit-icons if it gains gradient support, or if a flat mark is approved.

`apps/web/public/logo.svg` is the tight wordmark (no margin) for in-app brand marks; it is not an icon master.
